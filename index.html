Clavimit

Encrypt and decrypt Gmail messages locally.

Decrypt Email

Paste your RSA private key in PEM/PKCS#8 format, or load it from a file.

Encrypt Email

Paste the recipient's RSA public key in PEM/SPKI format or load it from a file.

Compose mode

Write the plaintext here. Only the encrypted message will be inserted into Gmail.

Tools

Generate RSA key pair

Optionally generate a new RSA key pair for use with Clavimit. You can also use an existing compatible RSA key pair.

Save your private key

Clavimit does not store your private key and cannot recover it. Save it somewhere secure - you will need it to decrypt messages sent to this key pair.
